# Source provenance

The baseline comes from the historical `mcp_events_prototype` source as inspected on 2026-10-09 (original development checkpoint: 2026-09-30). The original directory and its parents were not Git repositories. No historical commits are invented.

The requested GitHub remote was empty at clone time. The baseline commit contains original runnable Python code and offline tests, plus a repository-relative launch template and ignore rules. The next commit carries the reviewed media and local TTS extension.

Excluded: runtime/binding credentials, private message databases, callback/tunnel connection snapshots, private status/history documents, media, logs and cache. The original online service remains untouched. Cloning or pushing this code does not deploy it or authorize media permissions.
